TiTanX Lab GUI Wizard Improvements
------------------------------------
- Custom progress dialog (skin-independent, always visible)
- Percentage display during download
- Direct binary restore with auto-click after install
- Addon activation (enable_addons) after build install
- Reliable Kodi close dialog after installation
- ADDONTITLE_PLAIN for all dialog title bars
- All bare excepts replaced with proper exception handling
- Duplicate code removed (safe_filename helper)
- Dead code and effectless globals removed
- KodiVer() updated for Kodi 22 support
- New addon ID: plugin.program.TiTanX_LAB-GUIWizard
- New branding: TiTanX Lab GUI Wizard
  (TiTan silver · X lime · Lab dimgray · GUI Wizard white)
